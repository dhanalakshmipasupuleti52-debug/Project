STACK

About Stack

A Stack is a linear data structure that follows the LIFO (Last In First Out) principle. The last element inserted is removed first.

Applications

  • Undo operations
  • Function call management
  • Expression evaluation
  • Browser navigation
  • Recursion handling

Advantages

  • Simple implementation
  • Fast insertion
  • Fast deletion
  • Efficient memory usage

Disadvantages

  • Limited access
  • Only top element accessible
  • Not suitable for random access

Time Complexity

Operation Complexity
Push O(1)
Pop O(1)
Peek O(1)
Search O(n)
