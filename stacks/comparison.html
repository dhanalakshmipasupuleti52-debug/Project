📈 Time & Space Complexity Comparison



Operation Array Linked List Stack Queue
Access O(1) O(n) O(n) O(n)
Search O(n) O(n) O(n) O(n)
Insertion O(n) O(1) O(1) (Push) O(1) (Enqueue)
Deletion O(n) O(1) O(1) (Pop) O(1) (Dequeue)
Peek / Front O(1) O(n) O(1) O(1)
Space Complexity O(n) O(n) O(n) O(n)


Key Observations

  • Arrays provide the fastest random access (O(1)).
  • Linked Lists provide efficient insertion and deletion (O(1)).
  • Stacks are ideal for LIFO operations.
  • Queues are ideal for FIFO operations.
  • All structures require O(n) space.
