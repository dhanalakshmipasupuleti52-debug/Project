📈 Time & Space Complexity Comparison

Operation Array Linked List Stack Queue
Access O(1) O(n) O(n) O(n)
Search O(n) O(n) O(n) O(n)
Insertion O(n) O(1) O(1) O(1)
Deletion O(n) O(1) O(1) O(1)
Peek / Front O(1) O(n) O(1) O(1)
Space Complexity O(n) O(n) O(n) O(n)

Key Observations

  • Arrays provide the fastest random access with O(1) complexity.
  • Linked Lists support efficient insertion and deletion operations.
  • Stacks follow the LIFO (Last In First Out) principle.
  • Queues follow the FIFO (First In First Out) principle.
  • All structures generally require O(n) space complexity.
