ARRAY DATA STRUCTURE

About Array

An array is a linear data structure that stores elements of the same type in contiguous memory locations. Each element can be accessed using its index.

Applications

  • Student marks management
  • Searching algorithms
  • Sorting algorithms
  • Matrix representation
  • Database records

Advantages

  • Fast random access
  • Simple implementation
  • Efficient memory usage
  • Easy traversal

Disadvantages

  • Fixed size
  • Insertion is costly
  • Deletion is costly
  • Possible memory wastage

Time Complexity

Operation Complexity
Access O(1)
Search O(n)
Insertion O(n)
Deletion O(n)
